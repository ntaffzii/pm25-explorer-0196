# PM2.5 Explorer

ระบบสำรวจคุณภาพอากาศ PM2.5 ของประเทศไทย (รายวิชา 1145100 Data Science Toolbox)

## วิธีติดตั้ง
uv sync - จะติดตั้งสภาพแวดล้อมอัตโนมัติ (ถ้ามีไฟล์ pyproject.toml)


## แหล่งข้อมูลและเงื่อนไขการใช้งาน
- **แหล่งข้อมูล:** กองจัดการคุณภาพอากาศและเสียง กรมควบคุมมลพิษ (Air4Thai) กระทรวงทรัพยากรธรรมชาติและสิ่งแวดล้อม
- **URL บริการข้อมูล:** `http://air4thai.pcd.go.th/services/getNewAQI_JSON.php`
- **ผลการตรวจ `robots.txt`:** จากการตรวจสอบด้วย `RobotFileParser` ที่ `http://air4thai.pcd.go.th/robots.txt` ผลลัพธ์คือ `can_fetch = True` (ไม่พบข้อกำหนดหรือข้อห้ามในการดึงข้อมูลจาก endpoint นี้)
- **เงื่อนไขการใช้งานและการอ้างอิงแหล่งที่มา:** ข้อมูลนี้เผยแพร่เพื่อสาธารณประโยชน์ในการติดตามสถานการณ์คุณภาพอากาศ การนำข้อมูลไปใช้ควรระบุแหล่งที่มาอย่างชัดเจน: *"ข้อมูลจากกองจัดการคุณภาพอากาศและเสียง กรมควบคุมมลพิษ (Air4Thai)"*
